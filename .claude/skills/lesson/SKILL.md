1. Read `.claude/progress/tracker.md`, `learner-profile.md`, and `gate-log.md`.
2. If the current lesson has unreviewed work, review it first and do not start anything new.
3. If the previous lesson's mastery questions have not been passed, finish those first.
4. Otherwise recap the last concept with 2-3 questions, then teach the next lesson.
5. Lessons already exist in `journey/`. Teach the next one a concept at a time, in chat, instead of pointing at the whole file. Adapt it to the learner's profile.
6. Verify any Temporal behaviour against the official docs, and link what you used.
7. Run any new lab code before handing it over.
8. In chat, give a short version and one clear next action. Update the tracker.
