# Lesson 6: Phase 1 Gate

Type `/gate` when you're ready. Only passing this opens Phase 2.

## How to prepare

Without notes, you should be able to:

- [ ] Explain the problem Temporal solves using a real example
- [ ] Say why a normal Python process isn't enough
- [ ] Say why retries alone aren't enough
- [ ] Explain durable execution and replay
- [ ] Say where Workflow state lives
- [ ] Define each part of the cast in your own words
- [ ] Draw the architecture from memory
- [ ] Walk through the Pull the Plug table

## What the gate covers

| Part | You'll be asked to |
|---|---|
| Conceptual | Answer the plan's 12 Phase 1 questions, with real examples |
| Coding | Show your finished `checkout_v2.py`, and predict its behaviour under a new crash point |
| Failure | Reason through a scenario you haven't seen |
| Architecture | Draw the diagram and explain the Worker disappearing at each point |

If any part isn't solid, your mentor reteaches it with a different example, and you try again. That's how this is meant to work.
